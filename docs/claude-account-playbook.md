## 2. Выводы из чужих кейсов: за что банят и когда прилетает KYC

1. **Регистрация + оплата в один день = фрод-триггер:**
   * Оба успешных сценария включали **2–4 дня прогрева на бесплатном тарифе (Free)**: обычные бытовые/рабочие вопросы в веб-чате или мобильном приложении без привязки карты и без подключения терминала.
2. **Оплата через App Store (iOS) — главный чит-код против Stripe Radar:**
   * При покупке подписки внутри iOS-приложения Claude деньги списывает **Apple**, а не Stripe.
   * Anthropic получает только обезличенный `App Store receipt`: они **не видят** ни таджикский BIN карты, ни биллинг-адрес, ни email основного Apple ID (`evv.vprod@gmail.com`).
   * Полностью исключается проблема `Geo-mismatch` (когда IP = Нидерланды, а карта = Таджикистан).
3. **Бамп до Max ($100 / $200) в вебе почти гарантированно вызывает KYC (Persona):**
   * На тарифе **Pro ($20)** с небольшим прогревом и резидентским IP проверка документов (Persona) почти никогда не прилетает.
   * При переходе на **Max ($100)** в вебе почти всегда вылезает Persona KYC.
   * Загружать сгенерированные/нейросетевые паспорта в Persona бесполезно (система отклоняет их и ставит кулдаун на несколько дней, а деньги за подписку не возвращает).
   * **Вывод для нас (без не-РФ паспорта):** безопаснее держать **2–3 изолированных аккаунта Pro ($20)** (переключая их через `./scripts/orca-clean-agent.sh run <profile> claude`), либо делать апгрейд только через подписки iOS App Store после 1–2 недель жизни аккаунта на Pro.
4. **Паттерн выжигания лимитов:**
   * Выжигание 5-часовых сессионных и недельных лимитов «в ноль» от сброса до сброса подряд — сильный сигнал для антифрода. Стараться не доводить сессию до жесткого отбоя каждую смену.

## 3. Пошаговый регламент создания нового аккаунта (SOP)

### Шаг 1. Очистка хвостов на Mac (перед первым запуском)

В `~/.claude/` не должно оставаться старых файлов телеметрии (`~/.claude/telemetry/1p_failed_events.*.json`), бэкапов `.claude.json` и старого `machineID`/`userID`, иначе при случайном запуске Claude Code без профиля он отправит в Anthropic старые UUID забаненного аккаунта.

Запустить очистку:
```bash
./scripts/orca-clean-agent.sh purge-legacy
./scripts/orca-clean-agent.sh check
```
Убедиться, что `check` выводит:
`[OK] Clean Exit Verified: IP=78.143.239.176 | Country=NL | ASN=AS6830 Liberty Global Europe Holding B.V.`

### Шаг 2. Регистрация аккаунта (iPhone под Happ `NL-Residential-ISP` или чистый профиль браузера)

1. Включить в **Happ** на iPhone профиль `NL-Residential-ISP` и проверить `https://ipinfo.io/json` (`78.143.239.176`, `NL`).
2. Переустановить приложение **Claude by Anthropic** из App Store (если в нем раньше был вход в старый аккаунт).
3. **Выбор почты / метода входа:**
   * ⚠️ **НИКОГДА не светить `evv.vprod@gmail.com`!**
   * **Вариант А:** Нажать `Continue with Apple` → обязательно выбрать **«Скрыть e-mail» (Hide My Email)**, чтобы создался чистый `@privaterelay.appleid.com`. *(Если раньше на этом Apple ID уже был вход в Claude через Apple — предварительно удалить связку в `Settings -> Apple Account -> Sign in with Apple -> Claude -> Delete`).*
   * **Вариант Б:** Зарегистрироваться по отдельной чистой почте `@icloud.com` или прогретой `@outlook.com`. (Оплата внутри приложения Claude всё равно пройдет через таджикский App Store на телефоне — почта аккаунта Claude и почта App Store не связаны).

### Шаг 3. Подтверждение по СМС (Правила выбора номера)

У Anthropic стоит фильтр **Twilio Lookup**, который до отправки СМС проверяет тип номера (`carrier_type`) и блокирует виртуальные/M2M/VoIP диапазоны с ошибкой:
`Unable to send verification code to this number, try a different number or try again later`.

* **Правило 1 (Англия `+44` — самая высокая проходимость в активаторах типа OnlineSim / 5sim / GrizzlySMS):**
  * Брать **Великобританию (`+44` United Kingdom)**.
  * Проверять, чтобы номер после `+44` состоял из **10 цифр** и начинался на **`74...`**, **`75...`**, **`77...`**, **`78...`** или **`79...`** (например, `+44 740 505 9850` — реальный мобильный оператор O2 / Vodafone / EE / Three).
* **Правило 2 (Нидерланды `+31`):**
  * Реальный мобильный номер Нидерландов **всегда** начинается строго на **`+31 6...`** (9 цифр после `+31`, например `+31 6 12345678`).
  * ❌ **НЕ вводить номера `+31 970...`** (11 цифр) или кривые склейки вроде `+31 420...`! Префикс `+31 97` — это M2M/IoT модемы, Claude всегда блокирует отправку на них и вешает временный `rate limit error` на форму.
* **Правило 3 (Кулдаун при `rate limit error`):**
  * Если после 2–3 неудачных номеров вылезла ошибка `rate limit error` — **не нажимать кнопку отправки 15–20 минут** (каждое нажатие продлевает блокировку). Через 20 минут с первой попытки ввести валидный `+44 7...`.

### Шаг 4. Прогрев на Free (Дни 1–3)

1. **Не покупать подписку в день регистрации!**
2. В течение 2–4 дней заходить в аккаунт с iPhone (под `NL-Residential-ISP`) и/или из **отдельного нового профиля браузера на Mac** (Chrome / Arc / Dia — именно отдельный профиль, не инкогнито, чтобы сохранялись куки `claude.ai`).
3. Задавать по 3–5 обычных вопросов в день (ресерч, бытовые вопросы, обсуждение текста/кода в вебе).

### Шаг 5. Покупка Pro ($20) через App Store (День 3–4)

1. Открыть приложение Claude на iPhone (под включенным `NL-Residential-ISP`).
2. Нажать **Upgrade to Pro ($19.99/мес)** и оплатить через стандартное окно App Store (Face ID).
3. Деньги списываются с привязанной к App Store карты Visa Таджикистана, а Anthropic получает только подтверждение от Apple (без участия Stripe).

### Шаг 6. Работа в Claude Code CLI на Mac

1. Создать и запустить изолированный профиль через скрипт:
   ```bash
   ./scripts/orca-clean-agent.sh run acc1 claude
   ```
   *(Скрипт автоматически проверит, что текущий IP — `78.143.239.176 NL`, и запустит Claude с изолированным `CLAUDE_CONFIG_DIR=~/.claude-profiles/acc1` и общими скиллами).*
2. Открыть ссылку OAuth-авторизации **в том же выделенном профиле браузера**, где залогинен этот аккаунт.
3. **Для второго аккаунта** (например, на почте `@outlook.com` с iPad):
   ```bash
   ./scripts/orca-clean-agent.sh run acc2 claude
   ```
4. **Правила гигиены при работе:**
   * Никогда не запускать голый `claude` без `./scripts/orca-clean-agent.sh run <profile> claude` (либо прописать алиас в `~/.zshrc`).
   * Не выжигать 5-часовые сессии в ноль каждую смену подряд; при большой нагрузке чередовать `acc1` и `acc2`.
