## Восстановление

Нужен существующий приватный age-ключ проекта. Не добавляйте его в Git.
Сначала расшифруйте копию в локальный каталог вне репозитория:

```bash
mkdir -p "$HOME/.config/outpost"
(umask 077; age --decrypt \
  --identity "$HOME/.config/sops/age/outpost.key" \
  surge/Default.conf.age > "$HOME/.config/outpost/Surge-restored.conf")
```

Проверьте восстановленный файл перед импортом в Surge. Читаемый `Default.conf`
с плейсхолдерами не предназначен для непосредственного подключения: проверка
Surge останавливается на заменённом приватном ключе WireGuard.

## Версионирование

Изменения этих файлов отслеживаются Git, но автоматической синхронизации с Surge
нет. При следующем сохранении обновляйте обе версии: зашифрованный оригинал
и читаемую копию без секретов. Не копируйте рабочий конфиг в репозиторий открытым
текстом. Не публикуйте вывод CLI `dump profile`: он также содержит секреты.
